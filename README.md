# Intensive Code Camp — Full-Stack Web & Generative AI Development Using MERN

This repository contains my learning materials, labs, exercises, assignments, notes, and practical work from the **Information Technology Institute (ITI) Intensive Code Camp — Full-Stack Web & Generative AI Development Using MERN** program for the **2025/2026 academic year**.

---

## 📌 Program Overview

The ITI Intensive Code Camp is a **product-based, project-focused program** designed to develop practical skills in modern full-stack web development and Generative AI.

The program covers both **MEARN and MERN stack technologies**, along with software engineering practices, testing, security, DevOps, and AI-assisted development.

|                     |                                                                                        |
| ------------------- | -------------------------------------------------------------------------------------- |
| **Program**         | Intensive Code Camp — Full-Stack Web & Generative AI Development Using MERN            |
| **Academic Year**   | 2025/2026                                                                              |
| **Duration**        | 618 hours                                                                              |
| **Learning Period** | Approximately 7 months                                                                 |
| **Approach**        | Synchronous learning, guided practice, and project-based learning |

---

The program prepares graduates for roles including:

## 📚 Curriculum

The official program curriculum covers several areas of full-stack development, software engineering, employability, and Generative AI.

### 1. JavaScript Programming — 12%

Topics include:

* Advanced JavaScript
* Modern JavaScript (ES6+)
* TypeScript Fundamentals
* jQuery Fundamentals


### 2. Front-End Web Development — 19%

The frontend part of the program focuses on building modern, responsive, and user-friendly web applications.

Topics include:

* Client-Side Technologies
* HTML5
* CSS3
* UI/UX Design Principles
* CSS Preprocessors
* Responsive Web Development
* Bootstrap



### 3. MEARN / MERN Stack Development — 34%

The stack development part covers modern JavaScript technologies for building complete web applications.

Topics include:

* Node.js Fundamentals
* Express.js
* NoSQL Database Fundamentals
* Angular Fundamentals
* React.js
* Next.js Fundamentals
* Material UI for React.js
* NestJS
* GraphQL API
* REST APIs

### 4. Web Development Tools & Management Techniques — 11%

Topics include:

* JavaScript Unit Testing
* Progressive Web Applications (PWA)
* JavaScript Design Patterns
* Source Control / Version Control
* Secure Coding
* Docker Fundamentals

### 5. Generative AI Skills — 5%

The Generative AI part of the program focuses on integrating AI into modern software development.

Topics include:

* Introduction to Generative AI
* Prompt Engineering
* AI-Powered Coding Assistant Tools
* AI-Assisted Software Development
* Developing Generative AI-Based Software
* Vibe Coding


### 6. Workshops — 8%

The program also includes workshops covering important foundations and professional development practices:

* Operating Systems Workshop
* Computer Networks Workshop
* Database Workshop
* Software Testing
* Agile Workshop

### 7. Employability Skills — 11%

The program includes professional and career-oriented training:

* Effective Communication Skills
* Effective Presentation Skills
* CV Writing & Interviewing Skills
* Freelancing Fundamentals
* Work Ethics Workshop

HTML5 & CSS3 - Lab 2 Tasks

Task 1 – WebStorage Polyfill

Create a polyfill for localStorage and sessionStorage using cookies.

Task 2 – SVG & MathML

Draw a right triangle using SVG and display the Pythagorean theorem using MathML.

Task 3 – Canvas Animation

Animate a line diagonally across a canvas using requestAnimationFrame.

Task 4 – Landscape Gradient

Draw a simple landscape with sky and grass using linear gradients and a black rectangle object.

Task 5 – Arc & Radial Gradient

Draw a circle with a radial gradient fill and a centered letter inside it, fully circular with no square edges.


HTML5 & CSS3 - Lab 2 Bonus

Bonus Task 1 – Cookie Library Test

Implement a simple interface to set, get, delete, list, and check cookies using buttons and inputs.

Bonus Task 2 – WebStorage Polyfill Test

Test the localStorage polyfill using a key-value interface with save, get, remove, and clear functions.
